# Stack técnico — PataHogar

- **Base de datos:** MySQL Community Server (standalone, local en `C:\mysql`)
- **ORM / query builder:** Knex.js
- **Backend:** Node.js + Express
- **Chat en tiempo real:** Socket.io
- **Autenticación:** JWT (access + refresh token) + bcrypt, sin verificación por email
- **Subida y procesamiento de imágenes:** Multer + Sharp
- **Proceso persistente (backend):** PM2
- **Frontend:** React + Vite
- **Ruteo frontend:** React Router
- **Estilos:** CSS propio (sin framework de UI)
- **Cliente de tiempo real (frontend):** Socket.io-client
